# HED3505-EVALUATION-ANALYSIS-LAB-08E
## Instructor Signature Integration

Date: 21 September 2026
Status: APPROVED / IMPLEMENTED

## Decision
Use the instructor-provided signature on the HED3505 course-completion certificate.

## Implementation
- signature traced from the instructor-provided image
- embedded as an inline vector SVG in certificate.html
- no external image request is required
- signature is placed above the instructor name
- screen and A4 landscape print layouts are supported
- no university logo is used

## Boundary
The signature is used only in the HED3505 course-completion certificate template in this controlled preview.
