## Current student journey
1. START HERE / Orientation
2. Read / Review the complete case and concepts
3. Mission 1 — Evidence Detective
4. Submit → Guided Feedback → Revise → Reflect
5. Mission 2 — Build & Challenge the Evaluation
6. Self-Audit + Missing Evidence Challenge → Submit → Guided Feedback → Revise
7. Mission 3 — Individual Evaluation Decision Challenge
8. Submit → Guided Feedback → Revise
9. Final Review → Key Terms → Common Confusions
10. Practice Exam → Answers/Explanations after attempt → Essay Practice → Final Checklist
11. Evidence-based Completion → Certificate eligibility

No peer, synchronous meeting, group hearing, or instructor presence is required for the approved v3.2 learning path.

## Mission 3 decision contract
The learner rotates through Evaluator → Evidence Auditor → Stakeholder → Decision Maker perspectives and builds:
Evidence → Interpretation → Limitation → Criterion → Judgment → Recommendation → Action → Re-evaluation.

Allowed decisions:
- CONTINUE
- CONTINUE WITH MODIFICATION
- COLLECT MORE EVIDENCE
- DISCONTINUE

There is no predetermined single correct final decision; defensibility is assessed.

Health Problem / Need → Logic Model → Objectives → Evaluation Questions → Indicators → Measurement & Instruments → Validity + Reliability → Data Collection → Analysis → Evidence → Interpretation → Criteria → Judgment → Recommendation → Action → Re-evaluation

## Certificate contract
Certificate means completion, not achievement. Eligibility requires completion of M1–M3, required submissions, required feedback viewed, required revision/reflection, Final Review, and Practice Check according to the approved rule. Issuance must be server-authoritative and idempotent. Public verification must expose only the approved privacy-minimal fields.
