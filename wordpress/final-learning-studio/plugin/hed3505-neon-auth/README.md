# HED3505 Neon Auth Bridge

Staging-oriented WordPress mini-plugin for HED3505 Final Learning Studio.

- Enqueues the approved Neon JS browser bundle only on WordPress page ID 117.
- Does not persist C1/C2/C3/Hearing responses by itself.
- Does not alter the active theme.
- Production activation remains a Human Approval Gate.
- The generated JS asset is supplied by CI during packaging and is not hand-edited.

Version: 0.1.0
