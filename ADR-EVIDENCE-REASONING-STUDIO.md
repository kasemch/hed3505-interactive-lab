# ADR — Coexistence of Five-Module Lab and A1–B3 Evidence Reasoning Studio

Date: 19 September 2026  
Status: ACCEPTED FOR CONTROLLED INTEGRATION PLANNING

## Context
The repository already contains an approved five-module Evaluation Design Lab with WS1–WS5. A separate A1–B3 digital activity stream has now passed real-device controlled preview acceptance.

## Decision
Preserve both structures.

- Five-module lab remains the primary evaluation-design progression.
- A1–B3 becomes an Evidence Reasoning Studio.
- A1–B3 aligns most directly with Module 4 (Data → Interpretation → Decision).
- No renumbering or replacement of WS1–WS5 is permitted in this phase.

## Consequences
Positive:
- no destructive curriculum rewrite
- preserves existing traceability
- allows immediate reuse of accepted mobile activities
- creates one coherent evidence-reasoning subpath

Constraint:
- course navigation must clearly distinguish the two structures
- portfolio must label artifact families to prevent confusion

## Revisit condition
Revisit only if the course team explicitly decides to redesign the five-module architecture.
