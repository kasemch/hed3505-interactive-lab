ความพึงพอใจสะท้อนการรับรู้ ไม่เท่ากับผลลัพธ์ทักษะ CPR; แยก Output กับ Outcome ตรวจหลักฐานหลายแหล่ง ตัวส่วน และคุณภาพเครื่องมือก่อนตัดสินผล

คำถามสะท้อนคิด: เมื่อความพึงพอใจสูง แต่ผลผ่านทักษะ CPR อยู่ที่ 38% ข้อสรุปใดที่หลักฐานรองรับ และประเด็นใดยังไม่อาจสรุปได้?
