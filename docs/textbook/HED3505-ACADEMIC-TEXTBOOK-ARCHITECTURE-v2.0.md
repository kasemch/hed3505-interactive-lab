## 3. Evidence register — core verified sources
ER-01 CDC Program Evaluation Framework, 2024. Six steps: assess context; describe program; focus evaluation questions/design; gather credible evidence; generate/support conclusions; act on findings. Cross-cutting actions and five evaluation standards. Primary source: CDC/MMWR 2024.
ER-02 CDC Program Evaluation Framework Action Guide, 2024. Practical guide for new/early-career evaluators applying the framework.
ER-03 WHO & UNESCO, Making every school a health-promoting school: Global standards and indicators, 2021.
ER-04 WHO, Guideline on school health services, 2021.
ER-05 WHO, Making every school a health-promoting school: implementation guidance, 2021.
ER-06 WHO SEARO, Roadmap for Implementation of Health Promoting Schools in the South-East Asia Region, 2022.
ER-07 WHO, Making every school a health-promoting school: implementation guidance for school health services, 2026.
Evidence rule: verify bibliographic metadata and claim-to-source match before final APA 7 binding; do not invent citations.

## 8. Assessment architecture
Essay 1 Design an Evaluation: Logic Model → Evaluation Question → Indicator → Instrument/Data Source → quality → collection/analysis → Criteria.
Essay 2 Use Evaluation Evidence: Evidence → Limitations → Interpretation → Criteria → Judgment → Recommendation → Action/Re-evaluation.
Rubric: concept accuracy 20%; evidence use 20%; analysis/reasoning 25%; criterion-based judgment 15%; recommendation/action 10%; clarity/systematic 10%.

## 9. Academic publishing standard
A4 print-first + screen-readable PDF; consistent heading hierarchy; numbered figures/tables; cross-references; glossary; APA 7; page headers/footers; page numbers; accessible reading order; bookmarks; alt text in digital source; adequate contrast; avoid decorative-only visuals; tables repeat header rows and state units/denominators.
Writing level: Thai undergraduate academic prose, explain technical terms at first use, progressively increase complexity, worked examples without leaking live-case answers.
