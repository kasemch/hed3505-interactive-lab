# HED3505 Certificate Design 01 — Classic Academic Navy–Gold

Status: SELECTED DESIGN BASELINE / NON-PRODUCTION
Course: HED3505
Certificate type: Certificate of Completion / ใบรับรองการสำเร็จกิจกรรมการเรียนรู้
Instructor: ผู้ช่วยศาสตราจารย์ ดร.เกษม ชูรัตน์

## Design baseline
- Landscape academic certificate.
- Navy–Gold visual system, off-white certificate field.
- Formal academic hierarchy; restrained ornament; print/PDF friendly.
- The AI concept image is design inspiration only. No generated seal, signature, learner data, certificate number, or institutional claim from the concept image is authoritative.

## Required certificate fields
- Learner approved display name.
- Course code HED3505.
- Certificate of Completion title.
- Completion date.
- Instructor: ผู้ช่วยศาสตราจารย์ ดร.เกษม ชูรัตน์.
- Opaque certificate ID.
- Verification QR/URL.
- Certificate/version identifier.

## Privacy rules
Do not print or expose score, submitted answers, attempt history, email, auth ID, raw learner ID, or internal database identifiers.

## Eligibility contract
Certificate is server-authoritative and may be issued only after required evidence confirms Mission 1, Mission 2, Mission 3, required submissions, guided feedback viewing, required revision/reflection, Final Review, and Practice Check. Page views alone never establish completion.

## Verification projection
Public verification is minimal: VALID / REVOKED / NOT FOUND; approved learner display name; HED3505; Certificate of Completion; completion date; instructor; certificate ID/version. No learning evidence or score is public.

## Synthetic QA
Use SYN-A as ELIGIBLE; SYN-B and SYN-C as LOCKED; SYN-X as DENIED. Synthetic certificate IDs are test-only and must never be represented as real certificates.

## Release holds
Production issuance, real-student issuance, public verification backed by production data, destructive migrations, and production database changes remain HOLD until runtime authorization/RLS/idempotency/privacy tests pass and Human Academic Authority approves activation.
