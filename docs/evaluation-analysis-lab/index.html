LAB 2 — IOC Analysis

คำนวณ IOC รายข้อ แล้วตัดสินใจว่าจะ RETAIN / REVIEW / REVISE / REMOVE พร้อมเหตุผล

สูตร IOC
IOC = ΣR / N

R = คะแนนผู้เชี่ยวชาญ (-1, 0, +1), N = จำนวนผู้เชี่ยวชาญ
