LAB 2 — IOC Analysis

2ΣRรวมคะแนนผู้เชี่ยวชาญ

4Decisionตีความร่วมกับเหตุผล
สูตร IOC
IOC = ΣR / N

R = คะแนนผู้เชี่ยวชาญ (-1, 0, +1), N = จำนวนผู้เชี่ยวชาญ
