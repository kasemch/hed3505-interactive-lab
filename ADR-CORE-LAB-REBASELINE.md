# ADR — HED3505 Core Digital Lab Rebaseline

Date: 19 September 2026  
Status: ACCEPTED

## Context
The accepted A1–B3 Evidence Reasoning Studio focuses on reasoning about evidence, but the course requires more direct practice in instrument quality and statistical analysis.

## Decision
Make the core digital lab sequence:

1. Instrument & Indicator Alignment
2. IOC Analysis
3. Reliability Analysis
4. Statistical Data Analysis
5. Evaluation Interpretation & Recommendation

Retain A1–B3 as supplementary evidence-reasoning activities.

## Consequences
- better alignment with applied evaluation practice
- preserves prior work without making it the main backbone
- creates a direct path from instrument design to evidence interpretation
- enables reusable student evidence artifacts
- requires synthetic teaching datasets for calculation activities
- requires explicit distinction between teaching data and master-case facts

## Hold
No production navigation change until the detailed LAB 2–4 learning design passes review.
