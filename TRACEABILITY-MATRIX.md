# HED3505 End-to-End Traceability Matrix

Canonical learning pattern:

**Prompt → Tap → Reveal → Discuss → Decide → Save**

Canonical evidence chain:

**Digital Activity → Worksheet → Assignment → Evidence Requirement → Reflection → Rubric → Feedback → Portfolio Artifact**

| Module | Digital learning path | Worksheet | Assignment | Evidence focus | Reflection focus | Rubric focus | Portfolio artifact |
|---|---|---|---|---|---|---|---|
| 1 | Problem → Indicator | WS1 Assessment Planning | Assignment 01 | issue, FACT/ASSUMPTION, indicator, evidence gap | Problem vs Indicator reasoning | problem-indicator alignment, evidence limits | WS1 |
| 2 | Indicator → Instrument | WS2 Instrument Blueprint | Assignment 02 | construct, instrument, item, scoring, design risk | hardest instrument-design decision | indicator-instrument alignment, design quality | WS2 |
| 3 | Content Validity → IOC → Reliability → Revision | WS3 Instrument Quality Record | Assignment 03 | validity, IOC, reliability, RETAIN/REVIEW/REVISE/REMOVE | how quality evidence changed the item decision | validity/reliability interpretation and revision justification | WS3 |
| 4 | Data → Interpretation → Decision | WS4 Interpretation & Decision Matrix | Assignment 04 | data, finding, alternative explanation, uncertainty, defensible decision | interpretation initially over-supported | evidence reasoning, uncertainty, non-causal overclaim control | WS4 |
| 5 | Integrated Evidence → Evaluation Plan | WS5 Integrated Evaluation Plan | Assignment 05 | question, indicator, instrument, evidence quality, decision rule, limitation | weakest part of integrated plan | alignment, traceability, decision rule, limitations | WS5 |

## Progressive portfolio

**WS1 → WS2 → WS3 → WS4 → WS5**

Each module must preserve the prior artifact as an input to the next learning decision.
