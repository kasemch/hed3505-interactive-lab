# HED3505 Active Learning Challenge Pack — AL-02

Status: APPROVED BASELINE / v3.2 INDEPENDENT-LEARNING ALIGNMENT

## Current learning progression
Orientation → Mission 1 → Guided Feedback → Revision → Mission 2 → Self-Audit → Missing Evidence Challenge → Guided Feedback → Revision → Mission 3 Individual Evaluation Decision Challenge → Guided Feedback → Revision → Final Review → Exam Readiness

## Mission 1 — Evaluation Detective
Purpose: distinguish Fact, Interpretation, Assumption, and Judgment; detect overclaiming.
Student response: Supported / Partly Supported / Need More Evidence + rationale + revised defensible statement.
Example uses approved CPR knowledge 81% evidence only; it does not assert program causation.

## Mission 2 — Build & Challenge the Evaluation
Purpose: construct a coherent evaluation chain and audit it independently.
Chain: Objective → Evaluation Question → Indicator → Data Source → Instrument → Quality Check → Criterion → Possible Decision.
Self-Audit: Coherent / Gap Identified / Cannot Yet Decide + location and rationale; revise to Final Chain.

### Missing Evidence Challenge
Purpose: prioritize decision-useful evidence under constraint.
Student selects one additional evidence item and specifies:
Evaluation Question → Missing Evidence → Data Source → Instrument → Rationale → Decision Improved.
Finish with Evidence Confidence: Low / Moderate / High + rationale.

## Mission 3 — Individual Evaluation Decision Challenge
Purpose: integrate the full evidence-to-action reasoning chain without requiring a group meeting, peer, or synchronous instructor presence.

The learner rotates through four perspectives:
Evaluator → Evidence Auditor → Stakeholder → Decision Maker.

Required reasoning chain:
Evidence → Interpretation → Limitation → Criterion → Judgment → Recommendation → Action → Re-evaluation.

Allowed final decisions:
- CONTINUE
- CONTINUE WITH MODIFICATION
- COLLECT MORE EVIDENCE
- DISCONTINUE

There is no predetermined single correct final decision. Assessment focuses on whether the decision is defensible from the available evidence, criteria, limitations, and stakeholder considerations.

## Historical note
The earlier School Health Evaluation Hearing and Peer Audit flow are superseded for current student-facing use by the v3.2 independent-learning design. Historical records may retain the old terminology solely for traceability and legacy storage compatibility.

## Design safeguards
- Uses only approved Arun Pattana case evidence.
- “Need More Evidence / COLLECT MORE EVIDENCE” remains an academically defensible response when justified.
- No teacher answer key is embedded in student-facing content.
- No causal conclusion is generated from descriptive data.
- Activities assess reasoning and traceability rather than a predetermined final verdict.
- Completion requires authoritative learning evidence; page views alone do not count.
