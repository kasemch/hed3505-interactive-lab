# HED3505-EVALUATION-ANALYSIS-LAB-REDESIGN-01
## Core Learning Architecture Rebaseline

Date: 19 September 2026  
Environment: CONTROLLED PREVIEW / NON-PRODUCTION

## Decision
APPROVED

The core digital learning architecture for HED3505 is rebaselined as:

LAB 1 — Instrument & Indicator Alignment  
LAB 2 — IOC Analysis  
LAB 3 — Reliability Analysis  
LAB 4 — Statistical Data Analysis  
LAB 5 — Evaluation Interpretation & Recommendation

The previously accepted A1–B3 Evidence Reasoning Studio remains available as supplementary learning activities and is no longer the primary course-lab backbone.

## Rationale

HED3505 requires learners to do more than classify evidence claims. The central applied learning sequence should include:

Evaluation Question
→ Indicator
→ Instrument
→ Content Validity
→ IOC
→ Instrument Revision
→ Pilot Data
→ Reliability
→ Data Collection
→ Statistical Analysis
→ Interpretation
→ Evaluation Judgment
→ Recommendation

This preserves the strongest logic already present in the existing five-module Evaluation Design Lab while adding explicit hands-on computation and interpretation for IOC, reliability, and statistics.

## Core lab outputs

### LAB 1 — Instrument & Indicator Alignment
Student work:
- connect evaluation question to indicator
- connect indicator to instrument/item
- identify criterion and evidence requirement

Output:
Instrument Blueprint

### LAB 2 — IOC Analysis
Student work:
- read expert ratings (-1, 0, +1)
- compute item-level IOC
- interpret result
- classify item as RETAIN / REVIEW / REVISE / REMOVE
- justify the decision

Core formula:
IOC = ΣR / N

Output:
IOC Analysis Sheet

### LAB 3 — Reliability Analysis
Student work:
- identify instrument/data type
- select an appropriate reliability approach
- interpret the resulting coefficient
- state what reliability does and does not establish

Candidate approaches:
- Cronbach's alpha for multi-item scales
- KR-20 for dichotomous items
- inter-rater reliability for multiple assessors
- test–retest reliability for stability over time

Output:
Reliability Report

### LAB 4 — Statistical Data Analysis
Student work:
- inspect raw teaching dataset
- frequency
- percentage
- mean
- standard deviation
- table/chart
- interpretation
- comparison when appropriate to the lesson

Output:
Statistical Analysis Sheet

Important:
Any dataset added for practice must be explicitly labeled "synthetic teaching dataset" and must not be presented as a new fact about โรงเรียนอรุณพัฒนา.

### LAB 5 — Evaluation Interpretation & Recommendation
Student work:
- integrate instrument quality evidence
- integrate IOC/reliability/statistical results
- distinguish finding / interpretation / judgment / recommendation
- identify uncertainty and missing evidence
- make a defensible recommendation

Output:
Evaluation Report
